# Contributing / maintainers

## Plugin ID

The shipping plugin uses development ID `1066127`. For a widely distributed public build under your own name, register an ID at [Maxon Plugin Cafe](https://developers.maxon.net/) and change `PLUGIN_ID` near the top of `plugins/AxisCenterEach/AxisCenterEach.pyp`.

## Repo layout

- Plugin source: `plugins/AxisCenterEach/AxisCenterEach.pyp`
- Plan / spike notes: `PLAN.md`, `SPIKE.md`
- Driver decision: `docs/axis-center-driver-decision.md`

## Releases

Zip just the `.pyp` for GitHub Releases so downloaders get a single file to drop into their prefs `plugins` folder.
